Cara ou Coroa

Um jogo simples de Cara ou Coroa desenvolvido em Python, criado como parte da minha prática de programação.

O jogador escolhe entre Cara e Coroa, enquanto o computador faz uma escolha aleatória. No final, o programa informa se o jogador ganhou ou perdeu.

🎮 Como funciona

O programa apresenta as opções:

1 - Cara
2 - Coroa

O jogador escolhe uma opção.
O computador sorteia Cara ou Coroa aleatoriamente.
O programa mostra as escolhas.
O resultado informa se o jogador ganhou ou perdeu.
Após a rodada, é possível jogar novamente ou encerrar o programa.
O programa também possui uma validação para impedir escolhas diferentes de 1 ou 2.
